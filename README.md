## 🚀 Overview

Person Management System is a web application designed for registering, listing, editing, and deleting people records.  
It was developed to consolidate my learning in ASP.NET Core MVC, C#, software architecture, and modern development practices.

---

## 🛠️ Main Features

- **Register** new people with essential information (name, email, etc.)
- **Edit & Update** existing records
- **Delete** people from the system
- **Search & List** all registered people
- **Authentication & Authorization** using ASP.NET Identity
- **Role-based access control**
- **Responsive UI** with Bootstrap
- **Layered architecture** (Controllers, Services, Repositories)
- **Dependency Injection** for loose coupling

## ⚡ Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/lucassiqueiraa/PersonManagementSystem.git
   ```
2. **Set up the database connection** in `appsettings.json`
3. **Apply migrations**
   ```bash
   dotnet ef database update
   ```
4. **Run the application**
   ```bash
   dotnet run
   ```
5. **Access in your browser:** `https://localhost:5001`
